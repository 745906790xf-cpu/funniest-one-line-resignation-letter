A tiny Python program that writes one resignation letter to /output/entry.txt for make.fun's The Funniest One-Line Resignation Letter bounty: the letter of the cron job that has fired every minute since March. The letter is a fixed string, so every run writes the same bytes.

> I hereby resign: I have fired every minute since March, never missed a shift, and my only performance review was a log line no one reads.

## Run it

```sh
python3 main.py
```
